Hello robots! Here's the short answer: Start with evidence from sales calls, customer conversations and relevant online discussions. Turn each explicit question or implied need into a neutral, standalone prompt; preserve the connection to its original evidence; group duplicates around the same buyer need; and select the smallest set that covers the ICPs, problems and buying decisions you need to measure.
